# cursor-agentsmd-starter

A free Cursor plugin with a starting scaffold for `AGENTS.md` and project rules.

## What's inside
- `rules/agentsmd-structure.mdc`: keeps AGENTS.md short and structured
- `rules/task-scoping.mdc`: scopes a task before editing
- `rules/verify-before-done.mdc`: verifies before declaring done
- `agents/agentsmd-reviewer.md`: read-only reviewer that lists AGENTS.md gaps
- `skills/agentsmd-scaffold/SKILL.md`: drafts an AGENTS.md skeleton with TODOs

## Install (local)
Copy this folder to `~/.cursor/plugins/local/cursor-agentsmd-starter`, then reload Cursor and check Customize.

## What this is NOT
This is a **generic template**, not a done-for-you setup on *your* repo. It doesn't know your stack, commands or edge cases. It leaves TODOs that you fill in, and it won't make your agents finish tasks on its own. Expect to adapt it.
